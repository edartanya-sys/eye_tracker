# Eye Tracker — управление курсором взглядом

Программа для управления курсором с помощью взгляда через обычную веб-камеру. Разработана как ассистивная технология для людей с ограниченными возможностями.

## Как это работает
Камера снимает лицо → нейросеть MediaPipe находит глаза → алгоритм переводит взгляд в координаты экрана → моргание работает как клик мыши.



## Стек
Python, OpenCV, MediaPipe
